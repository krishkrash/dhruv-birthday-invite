# Dhruv's Spider-Verse Birthday Invitation

A single-page, self-contained birthday invitation (Spider-Man themed) for Dhruv's 3rd birthday.

- **When:** 6 December 2026 (Sunday), 12 noon onwards
- **Where:** German Block 64/6
- **Dress code:** Comfortable

`index.html` is fully self-contained (images embedded as data URIs) — just open it or serve it statically.

The RSVP form is currently in **preview mode** (not wired to a backend). To collect responses,
connect it to a Google Apps Script → Google Sheet endpoint.
